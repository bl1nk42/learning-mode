# Learning Mode

Learning Mode turns verified engineering evidence into reusable insights, wikis, and teaching material. This glossary keeps evidence provenance distinct from implementation status.

## Language

**Learning Artifact**:
A durable record produced from verified engineering evidence: an insight, index entry, wiki, generated Canvas, or teaching material.
_Avoid_: note, transcript

**Verified Reference**:
An external repository, standard, or primary document that has been inspected and cited for a claimed pattern.
_Avoid_: inspiration, named reference

**Reference-Derived Implementation**:
A delivered behavior whose design claim is supported by a Verified Reference and local tests.
_Avoid_: plan-based implementation, borrowed pattern

**Plan-Derived Draft**:
A local design inferred only from the improvement plan. It is not a Reference-Derived Implementation and cannot complete a reference-backed checklist item.
_Avoid_: implementation, completed feature

**Evaluation Artifact**:
A reproducible scenario, observed-usage record, or evaluation report used to assess whether Learning Mode helps a real workflow.
_Avoid_: synthetic prompt, score alone
