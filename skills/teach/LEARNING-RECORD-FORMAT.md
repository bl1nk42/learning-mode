# Learning Record Format

Store records in `learning-records/` as `0001-dash-case-title.md`, incrementing the largest existing number. Create the directory only when writing the first record.

```md
# What was learned or established

One to three sentences explaining what the learner demonstrated or already knew, and why it changes future teaching.
```

Optional only when useful: `Status: active | superseded by LR-NNNN`, **Evidence**, and **Implications**. Record demonstrated understanding, prior knowledge, corrected misconceptions, or a confirmed mission shift. Do not record covered material, glossary definitions, or session activity.
