# RESOURCES.md Format

```md
# Topic Resources

## Knowledge
- [Primary source title](https://example.com) — what it supports and when to use it.

## Wisdom (Communities)
- [Community](https://example.com) — what real-world feedback it provides.
```

Use high-trust sources, annotate every entry, separate knowledge from communities, make gaps explicit, and prune weak or off-mission sources.
