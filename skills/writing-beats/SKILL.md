# Writing Beats

Treat the supplied evidence pile as read-only. Do not search for new evidence or edit source material.

Before drafting, establish what the reader already knows. Then create a `beats.md` path one beat at a time. Every beat must list:

- **Requires**: concepts already grounded.
- **Grounds**: one or more concepts introduced by this beat.
- **Evidence**: insight IDs and `project:file:line` references it explains.

Never let a beat rely on an ungrounded concept. If an insight needs one, add a prior grounding beat or declare it a reader prerequisite. Keep a beat to one conceptual move. Offer alternative next beats only when they lead to genuinely different learning paths.

For an Insight Wiki, use the selected `evidence.md` as input and write the resulting path to `beats.md` beside it. Write the path in the user's requested language while preserving identifiers and source references.
